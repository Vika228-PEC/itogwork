# Weather Diary

**Автор:** Иван Иванов

**Описание:** Приложение для ведения дневника погоды с возможностью добавления, фильтрации и сохранения записей.

**Как запустить:**
1. Установите Python 3.x.
2. Установите зависимости: `pip install tkinter`.
3. Запустите: `python weather_diary.py`.

**Примеры использования:**
- Добавьте запись с датой, температурой, описанием и осадками.
- Используйте фильтрацию по дате или температуре.
- Сохраните данные в JSON и загрузите их обратно.
